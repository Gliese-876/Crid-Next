# AI 解析历史实测

本页仅记录 1.8.0 阶段的历史验证。AI 解析及其测试工具已在 1.15.0 删除，以下内容不代表当前应用功能；原始报告保留在旧版产物中。

`AiLiveInstrumentedTest` 当时在 Android 上调用旧版 `AiParser.parse`，并检查解析字段、导入预览、保存到磁盘及失败时的数据保留。当时使用显式启用的付费测试，常规测试没有调用服务。

## 本轮结果（2026-09-28）

共发起 **7 次真实请求**。最终纯合成 CSV 从界面“同意并发送”进入 AI 解析，返回 2 门课程、3 项安排；课程名、教师、地点、单双周、具体日期和钟点逐项通过，随后确认导入、磁盘复读和失败不覆盖检查均通过。该 CSV 不触发已知模板的本地教师核对。

| 验证项 | 结果 |
| --- | --- |
| 秋季匿名完整结构 | 11 门课、25 项安排全部字段通过；教师字段经过本地源文件核对 |
| 春季匿名完整结构 | 模型返回 14 门课、39 项安排，少 1 项；完整性检查阻止导入，不计作通过。正式原生解析保留全部 40 项 |
| 未知 CSV 真实 UI 流程 | 首次返回有一项无法使用；日期解码边界修复后，同一输入的发送、解析、确认保存和磁盘复读通过 |
| 取消与错误恢复 | 取消发送不改数据，错误配置保留文件，错误结果不能覆盖已保存课表 |

前 5 次请求有服务返回的用量，共 **23,112 tokens**（输入 6,320，输出 16,792）；2 次 UI 请求未采集 token 用量。未取得账单，不推算实际扣费。所有已执行批次均确认私有测试输入已清理。原始课程名、教师、地点和身份数据均未外发。

第六次请求的原始响应没有保存，因此不能把其具体失败字段认定为已确诊。离线检查确认了解码器的两个实质问题：有效日期搭配不适用的 `weekday=0` 会被丢弃，而正数星期与日期矛盾未被拦截。修复后新增的 6 项回归全部通过，第七次真实 CSV 流程也通过。

这些结果不能表述为“7 次全部通过”或“所有样例由模型独立正确解析”。分项结果、历史失败和安全快照清单在 `artifacts/qa-v1.8/AI-LIVE-SUMMARY.json`；`AI-LIVE.json` 仅表示最近一次运行。

## 样例

| 输入 | 核对范围 | 单次输出上限 |
| --- | --- | ---: |
| 秋季列表结构的匿名样例 | 完整 11 门课、25 项安排，保留待排时间、教师与周次对应、相邻节次的两项源记录 | 8,192 tokens |
| 春季列表结构的匿名样例 | 完整 14 门课、40 项安排 | 8,192 tokens |
| 未适配的 CSV | 同名课程合并、单双周、不同教师地点、具体日期和钟点 | 16,384 tokens |

两份列表文件在设备上由正式文字提取器读取，随后在内存中替换全部课程名、教师和地点；同步变换本地预期。发送内容使用明确的合成名称，保留中文、Latin 字母和数字的混排特性，保留周次、星期、节次、单双周、待排时间及教师对应关系。学期、文件标题、学生身份、账号、班号等其他字段不参与发送。任何无法归入周次、星期、节次及标点的原始文字都会在发送前被拒绝。

AI 输出与上述匿名预期逐字段比较。备注和额外说明允许文字差异，课程名、学分、周次、星期、日期、节次、钟点、教师、地点及待排状态必须一致。该测试验证完整匿名结构样例，不能表述为原始课表未经替换直接外发实测。

UI 检查覆盖发送前的完整文本预览、取消发送、配置错误后保留文件，以及真实返回结果的确认导入和磁盘保存。两份完整课表直接调用生产解析函数；第三份 CSV 从界面的“同意并发送”进入正式解析流程，直接预览并保存返回结果。该测试不把 HTTP 200 当作通过条件。

## 教师对应关系的本地核对

真实调用先后发现两类教师错误：明确的四人四段名单被留空；两人三段的歧义名单被擅自分配。为此，生产流程对已知列表表头增加本地核对：只有正式本地解析器能完整读取原文，且课程、周次、星期、节次或日期钟点、待排状态、地点全部对应，才用源文件教师映射核对 AI 字段。对应不明确时保留完整名单，不填入猜测的教师；其他课程元数据继续保留。课程或安排不匹配时阻止导入并提示核对，不用本地数据替换模型的错误时间。

这属于生产流程对已知模板的本地纠错，不表示模型本身的每个字段都正确。未知 CSV 不触发这一核对器，其完整 UI 流程仍需由真实 AI 调用通过字段验证。DeepSeek 的非思考请求另设 `temperature=0`，降低相同输入下的输出波动。

前两次调用记录服务报告的 token 数；第三次 UI 调用记录耗时和结果数量，不为收集用量新增全局测试钩子。未取得服务账单时不推算实际扣费。若主机等待超时，脚本先停止设备测试进程，再清理私有文件，防止测试在后台继续写入。
