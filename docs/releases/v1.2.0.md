# Crid Next 1.2.0

Crid Next 的首个正式发行版，适用于 Android 16 及以上版本。

## 主要功能

- **每天与每周，一眼看清。** “今天、课表、方案、设置”四个页面支持平滑滑动切换；手机使用底部导航，平板和大屏使用侧栏。周课表紧凑排列，常规屏宽下七天同屏，节次与时间集中显示在左侧。
- **完整保留授课安排。** 支持北师大课表文件中的多段授课与待排记录，教师、周次、地点与时间逐条对应。同名课程的跨周安排合并展示，只有同一周、同一天实际重叠的不同课程才标记冲突。
- **导入更直接。** 支持本地文件、系统分享及应用内教务浏览器。网页下载的课表可直接进入导入预览，确认后保存；多个学期与课表方案可独立管理。
- **分享与备份。** 可导出 PNG、PDF，语言跟随应用设置；也可导出能够重新导入的 Crid Next 数据文件。普通课程使用无边框色块，特殊状态通过阴影与虚线区分。
- **与系统外观协调。** 支持浅色、深色和系统主题；新图标以日历与课程格为主题，支持自适应形状及主题单色图标。“关于”页以应用图标为视觉焦点，提供作者信息、MIT 协议及第三方开源致谢。

## 从开发版迁移

本版本使用独立的正式签名，无法直接覆盖此前的 Debug 开发版。请先在旧应用中导出 **Crid Next 数据文件**，再卸载旧版、安装本次 Release APK，最后导入数据文件恢复课表。PNG 和 PDF 不能用于恢复课表。

卸载会清除旧应用的本地数据，请先确认导出的数据文件已保存。

## 已知限制

- 内置教务浏览器支持学校域名下的普通 HTTPS 文件下载；`blob:` 与 `data:` 下载暂不支持，可先保存文件，再从本地导入。
- 实际校园账号登录与下载链路尚未完成验证。
- 现有样例均来自珠海校区，北京校区暂按相同格式解析。
