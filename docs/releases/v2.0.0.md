# Crid Next 2.0.0

Crid Next 的首个公开开源版本，适用于 Android 12 及以上设备。

## 下载与安装

在 [GitHub](https://github.com/Gliese-876/Crid-Next/releases/tag/v2.0.0) 或 [Gitee](https://gitee.com/gliese-876/crid-next/releases/tag/v2.0.0) 下载 **Crid-Next-2.0.0.apk**，打开即可安装。两个平台提供同一安装包，支持 ARM64、ARM32、x86 和 x86_64。

已安装 Crid Next 正式签名版的用户可覆盖升级。使用 Debug 版或原 Flutter Crid 的用户，请先保存课表文件，再按 [使用说明](../../README.md)导入；Crid Next JSON 保存课程方案，学期与作息需要另行设置。

## 本次发布

- 查看今天与整周课表，管理多学期、多方案，编辑课程及单次授课安排。
- 从教务导出或本地文件导入课表，预览后确认；提供桌面小组件和上课前提醒。
- 按日、周、月、学期导出 PNG / PDF，或用 JSON 备份课程方案。
- 简体中文、繁體中文和 English README 相互跳转，均提供 GitHub 与 Gitee 下载入口。
- 新增 [JSON 课表示例](../../examples/timetable.json)及 AI 转换提示词，帮助处理内置解析暂不支持的格式。
- “关于”依次呈现作者、项目、特别鸣谢、原项目与许可，使用平台图标和 GitHub 头像，并标注原 Crid 已归档；姓名与归档状态的括号随语言统一。
- MIT 说明用信息图标与彩色底卡明确授权范围；第三方组件、品牌标志和头像分别说明适用许可或权利。

原 Crid 保留 Apache-2.0 许可和历史实现；Crid Next 是 Kotlin / Jetpack Compose 原生重写，有权许可的原创代码、文档与资源采用 MIT，具体范围见 [许可说明](../../LICENSING.md)。项目也记录了使用前沿模型开展 vibe coding 的实践。

## English

This is the first public release of Crid Next, a native Android timetable app for Android 12 and later. Download the APK from GitHub or Gitee; both hosts provide the same signed build. The release includes three-language guides, an importable JSON example, an AI conversion prompt, and links to both project repositories in the app.

Crid Next continues the original Crid project as a Kotlin / Jetpack Compose rewrite.
