# Crid Next 2.1.0

## 本次更新

- 在「设置 → 外观」可启用液态玻璃主题。悬浮导航透出滚动内容，高光随触摸移动，按钮按压后回弹，选中胶囊随页面滑动。Android 13 及以上支持实时折射，Android 12 保留实时磨砂和高光。
- 在「设置 → 课表显示」可选择显示午休、晚休或两者。起止时间按学期作息推算，休息时段与相邻课程块之间留有空隙。
- 「设置 → 外观」新增触感反馈开关，默认关闭。开启后，点选页面、切换周次和打开课程时会触发系统触感反馈。
- 底栏只采集周边的背景内容，外观设置变动时复用课表计算结果，头像采用无损压缩。

## 安装与校验

下载 **Crid-Next-2.1.0.apk** 后打开安装。已安装同一签名的正式版可以直接覆盖升级。最低支持 Android 12，安装包支持 ARM64、ARM32、x86 和 x86_64。[GitHub](https://github.com/Gliese-876/Crid-Next/releases/tag/v2.1.0) · [Gitee](https://gitee.com/gliese-876/crid-next/releases/tag/v2.1.0)

`manifest.json` 记录版本号、签名证书指纹和源码提交，`SHA256SUMS` 提供附件校验值。发行附件同时提供 AAB、匹配的应用源码、JExcelAPI 对应源码、许可证和重建说明。

## English

Crid Next 2.1.0 adds a Liquid Glass appearance, optional lunch and evening break rows in the weekly timetable, and a haptic feedback switch. The floating navigation responds to touch and samples the content behind it as you scroll. Real-time refraction requires Android 13 or later. Android 12 supports live blur and highlights. Download the APK to install or upgrade an existing official build.
