# 今天页文学摘句来源

本文为 1.9.0 的历史来源记录。1.10.0 已移除文学摘句，今天页顶部改为当前课程状态和下一节课提示。

1.9.0 当时离线收录 122 条中文、60 条英文原句。以下展示规则均为该版本的历史设计，2.0.0 不再打包或展示这些摘句。中文简体和繁体共享同一条引文身份；英语使用英文原作，不把中文诗句机器翻译后署给原作者。

每条摘句展示作者与篇名。下表保留原文链接，核对依据为原作全文，不使用营销语录页面。古籍采用通行简繁字形和句读，摘句结尾不挂句号；引文词语不作情绪化改写。近现代作品与英文原作保留内部标点，仅合并原版排版换行。

晨景、夕照和月夜分别按时段筛选；明确的春花、夏木、荷叶、秋菊按月份筛选。查看往日或未来日期时，只取不限定时刻的摘句。课程进度只决定候选情境，不改动原文，也不在句中插入课程数量。

页面在前台且可见时每 20 秒轮换；每个语言池保留最近 8 条，完成一轮洗牌后再取下一轮，同袋中优先换一位作者。简繁切换保留同一句，中英文各自记住上次阅读位置。主句及出处一起预留完整高度，轮换不推动下方课程。

原创应用代码继续采用 MIT 协议，引文保留原作者及作品署名。这里记录的是选取与校核依据，不是应用内提示文案。
