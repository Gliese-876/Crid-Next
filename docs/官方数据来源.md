# 官方数据来源与已确认口径

官方来源最初核实日期：2026-09-27。本文列出 2.0.0 采用的数据与实现范围，历史访问结果保留原日期。

## 默认学期及作息

北师大默认学期：2026-09-07 至 2027-01-10，18 周。第 1–16 周教学，第 17–18 周考试；1 月 11 日开始寒假。应用只预填模板，用户确认后保存。

- [北师大官方校历](https://www.bnu.edu.cn/xysh/syxx/xl/29736b4df42e4b5b971a5fc68a8d9ed7.htm)
- [2026–2027 第一学期教学安排](https://jwb.bnu.edu.cn/docs/2026-03/dc2edd85c53b482bb41e7f6d5383b331.pdf)
- [北京校区教学作息](https://jwb.bnu.edu.cn/bszn/xl/596e8f3e8d9e4d9da6bd85c51b830538.htm)
- [珠海校区教学作息](https://www.bnuzh.edu.cn/shzn/0a6478958d4347ff8d297f58891710a6.htm)

按上述来源核实并内置的两校区作息均为：08:00–08:45、08:55–09:40、10:00–10:45、10:55–11:40、13:30–14:15、14:25–15:10、15:30–16:15、16:25–17:10、18:00–18:45、18:55–19:40、19:50–20:35、20:45–21:30。

北京校区教学通知明确节假日停课不调课，课时由教师自主补足。国务院补班日不能据此推断补哪一天的课程；内置教学映射为空。数据模型可表达已确认的具体教学日期映射。

教务入口：[北京教务管理服务平台](https://ss.bnu.edu.cn/)、[珠海教务系统](https://jwxt.bnuzh.edu.cn/caslogin)。北京平台地址见[教务部 2025 年公告](https://jwb.bnu.edu.cn/docs/2025-04/3a889d3eba3a439e9d3e8cf5c8a4c320.pdf)。本次本机检查中，新入口返回 200 并显示统一身份认证及“教务管理服务平台”；旧 `zyfw.prsc.bnu.edu.cn` 的 HTTPS 连接失败，HTTP 返回 502。

北京站点对手机 WebView 的重定向链包含旧 HTTP CAS 地址。应用在加载前将同校域、默认端口的导航升级为 HTTPS，并保留原始编码的服务参数；保持证书验证和明文流量禁用。应用使用内置 WebView 登录学校页面，教务导出文件接入导入预览，也支持系统分享和本地文件导入。

最初四份样例来自珠海；2026-10-01 又加入北京校区的列表与周网格样例，现有六份样例均有独立逐字段预期。两校区共用解析器，具体格式覆盖见[解析验证](解析验证.md)。公开样例已匿名化，等价检查见[测试样例说明](../tests/README.md)。
