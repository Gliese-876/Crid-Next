# 桌面小组件设计

2.0.0 沿用 1.14.0 确立的布局：方形紧凑外观、宽矮双栏、分场景空态插画和完整点击区域。今日组件保留 2×2，周组件以首屏可读课程内容确定最低尺寸。组件内容使用系统字体，颜色随组件主题设置变化。

## 内容与尺寸

组件根背景内部保留 16 dp，课程卡左右保留 12 dp，最低高度卡片上下为 6 dp，其他紧凑卡上下为 8 dp，完整日程卡上下为 12 dp。日期作为主标题，紧凑尺寸使用 20 sp、较大尺寸使用 22 sp；较小的状态文字与日期同行。周列表的日期分组标题为 15 sp，七日概览中的日期数字为 18 sp。启动器提供的外部间距与组件自身的内容留白分别处理。课程名、时间、教师及地点保持清晰层级；长文字可换行或省略，完整信息通过点击进入应用查看。

今日紧凑组件优先展示当前或下一门课程，在最小尺寸保留时间、课名和地点，先隐藏教师，放大后显示完整字段和课程列表。今日最低内容宽度为 140 dp，默认字号下最低高度为 140 dp；200% 字体下最低高度提高至 240 dp，空间不足时完整显示放大提示。周组件按日展示课程，宽度足够且字体正常时增加七日快捷入口。高度不足 320 dp 时收起底部总数，让首张课程卡完整显示。大字体使用列表，避免压缩七个日期的触控区域。

默认字号下按实际尺寸调整内容，单位为 dp：

| 布局 | 内容变化 |
| --- | --- |
| 今日，高度不足 240、宽度不足 300 | 聚焦当前或下一门课 |
| 今日，高度不足 240、宽度达到 300 | 并排展示接下来的两门实际课程 |
| 今日，高度达到 240 | 展示完整当日日程；宽度达到 300 时分为两列 |
| 周，宽度不足 440 | 按日期分组展示课程列表；宽度至少 368、高度至少 360 时增加七日快捷入口，课程列表仍保留 |
| 周，宽度达到 440 | 两列按日展示，省去重复的七日快捷条；高度不足 480 时每日期显示前三门课，480–639 显示四门，640 及以上显示五门，其余通过明确的更多入口查看 |

普通字号下，有地点的 140 dp 高卡片优先保留地点并将课名限制为两行，160 dp 高允许三行课名，180 dp 高再显示教师。地点始终排在教师之前；完整日程中的地点和教师最多显示两行，紧凑摘要各保留一行。周统计始终使用全部授课安排，预览截取不会减少总数。今日完整列表最多显示 36 门，多出的课程仍有入口。

普通字号下，今日摘要始终保留地点，高度达到 180 dp 再显示教师；宽版在 220 dp 以下收起次要底部统计，把空间交给课程字段。该字段门槛随字体增大，200% 时为 290 dp。

宽矮双栏摘要在正常字号下使用原生填满容器，课程卡高度跟随实际宿主的可用内容区，两栏等高，文字垂直居中，底部只保留组件外侧留白。只有一门后续课程时铺满整行。较大字号和完整日程继续使用可滚动列表。

大字体提高双列断点，每列保留足够文字宽度；字体达到 150% 后，今日紧凑布局的高度分界提高到 320 dp。周组件最低高度随字体放大提高，200% 字体下为 440 dp，避免在仅剩日期栏的空间中挤入课程。

周组件默认声明 `targetCellWidth=4`、`targetCellHeight=5`，最小尺寸与最小缩放尺寸为 245×280 dp。宽度参考 [Android 小组件尺寸表](https://developer.android.com/design/ui/mobile/guides/widgets/sizing)中 Pixel 四列布局的 245 dp 下限；高度为两行课名、时间、教师及地点预留内容空间。启动器向应用提供实际 dp 尺寸，不提供当前网格列数；宽不足 245 dp 或高不足 280 dp 的组件提示放大，满足内容尺寸后自动恢复课程内容。受支持的周组件展示课程卡，不使用只有日期的周历作为小尺寸替代。

日期和课程保留点击入口，空课表、未选方案和大字体仍使用相同的内容安全区。截图与测试结果见 [1.10.0 迭代验证](迭代验证-1.10.md)。

## 方形、空态与点击

启动器只报告实际 dp 尺寸。今日紧凑组件的长短边比不超过 1.25 时，视为 2×2 对应的近方形类别：可见背景取短边作为边长并居中，外部透明容器适应宿主尺寸。普通字号单门课填满内容区，宽矮摘要、高日程与周组件维持原比例。响应式候选保留必要的方形实际尺寸，并防止它抢选其他信息档；大尺寸相同信息布局仍共用，最多 16 个变体。

空态提供窗边休息、课程结束后的书包与书本、准备课表三种原创矢量场景，分别适配浅深主题。紧凑方形为上下布局，宽矮组件为左右布局。图片大小由实际标题与正文测量后的剩余空间决定，文字使用原生均衡换行；大字号或空间不足时收起装饰。完整日程中的历史课程继续保留，周组件真正无课程时不再显示空白七日列表。

根背景、内边距、插画及空态正文都有默认打开入口。ListView 采用受内容区高度限制的 wrap_content，短列表余白由父容器接收点击；原有行间距移入可点击行内，双栏间隙和较短列下方也有路由。日期与课程的具体入口优先，手势滚动保留。验证使用真实触摸事件，详见 [1.14.0 迭代验证](迭代验证-1.14.md)。
