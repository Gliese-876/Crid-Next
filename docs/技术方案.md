# Crid Next 技术方案

本文说明当前实现，最低运行版本为 Android 12（API 31），1.11 已移除 HDR 控件功能；`compileSdk` 与 `targetSdk` 均为 37。兼容改动与验证范围见 [Android 兼容性](Android兼容性.md)，当前变更见 [1.15.0 迭代验证](迭代验证-1.15.md)，HDR 移除见 [1.11.0 迭代验证](迭代验证-1.11.md)，历史实现见 [1.10.1 迭代验证](迭代验证-1.10.1.md)，图标延续 [1.7.1](迭代验证-1.7.1.md) 的设计。

## 模块及数据一致性

`:core` 是可独立测试的 Kotlin/JVM 模块。所有界面、导出、小组件及通知统一调用 `ScheduleEngine`。课程身份使用 NFKC 全半角归一化、首尾 trim 和 Locale.ROOT 小写，并忽略中西文边界的排版空格；普通英文内部空格保留。同名课程合并身份，不合并差异授课安排。

界面与可视化导出使用 `displayCourses` 聚合同一课程的显示记录。同名、同显示日期与相同起止时间的记录先形成一张课程卡；同一授课上下文的相邻节次再合成连续课程，显示跨度包含中间课间。连续节次合并只处理按节次安排且未指定独立钟点的记录，要求课程身份、日期、周次、星期、教师、地点、备注及状态一致，且前段结束节次加一等于后段开始节次；仅钟点接近、跳节或授课信息不同的记录不据此合并。合成的代表记录只供布局使用，`DisplayCourse.occurrences` 与底层 `Lesson` 保留原始记录。

其他周的同名记录与现有卡片时间相交且周次不相交时，可并入该卡片。本周实际授课记录优先提供位置、时长、教师和地点；其他周记录不会拉长本周课程。详情与导出从原始记录读取各周对应的教师、地点和时间，不把合成的显示跨度追加成一条授课记录。

课程冲突要求不同课程在同一实际日期的授课时间重叠；仅在课表上占据相同位置的跨周记录不算冲突，非本周或停课记录不冒充当天实际授课。布局中的位置分组与业务冲突分开处理。

课表方案、学期和设置形成一个不可变 `AppState`。仓库用 Mutex 串行化写操作，用 `AtomicFile` 先写新状态、成功落盘后再发出 StateFlow；解析、预览和取消均不写正式数据。损坏文件保持原样并阻止覆写。平台通知更新失败不会将已完成保存报告为失败。

授课记录完全去重字段：排序去重后的周次、星期、起止节次、具体日期、起止时间、地点、教师、备注。学分和 extra 字段差异单独保留。课程颜色由名称分配并持久化，新课程从 14 色调色板开始分配，同方案撞色时选取其他色值；已有颜色身份保持不变。`CourseColors.swatch` 保留存储颜色，在浅色主题下将课程色按 16% 混入背景，低明度课程色采用 20%；深色主题先将课程色与白色混合，再按 24% 混入背景。文字对比同时考虑底色及休假斜线。课程之间用颜色区分，课程卡保留名称与授课信息，不增加编号或形状标记。

新建和编辑学期按当前周起始设置填写完整周：周一模式从周一至周日，周日模式从周日至周六。原生日期选择器禁用其他星期，输入模式和确认按钮也校验边界；编辑器保留最近两次手动编辑字段，第三项自动计算。起止日均包含在内，天数须恰为周数的七倍。旧数据读取保持兼容；未对齐学期在编辑时显示原值并要求调整，打开或取消不写入。修改全局周起始设置不会批量改写已保存的学期日期。

课程编辑使用 `CourseEditTarget` 捕获当前逻辑课程的全部来源记录。仓库在同一互斥锁内校验当前方案与快照，只替换目标记录，保留其他并发变化；保存失败时保留编辑草稿。课程详情排序前记录原始来源 ID 和索引，单条删除只影响该条安排覆盖的全部周次；最后一条来源安排移除后，其学分和附加信息保留到仍存的同名课程。新安排默认周次使用学期周数，历史记录中已有的额外周次可保留，不扩散到新安排。

## 导入

本地解析识别文件内容，而不是只看扩展名。支持经过样例验证的 BIFF XLS、HTML 表格 XLS，以及统一结构的 XLSX 与版本化 JSON 交换文件。ZIP/XML 输入限制体积并禁止外部实体；损坏和不支持输入给出失败结果。

源文件明确空排课且周次已知时，使用 unscheduled=true 保留周次、教师和原文，允许完整导入；此类记录从待排入口查看，不生成虚假日期或提醒。真正歧义、损坏、缺少周次等仍以 unresolved 或 errors 处理。教师按源授课段一一绑定；名单与周段无法唯一对应时保留原名单并提示。地点、教师、学分缺失不补造。学期不匹配必须明确处理；周次和节次超限必须调整目标学期或源内容。

获取、解析、选择目标、预览、确认、原子保存依次执行。替换仅更新目标方案，合并保留不同授课记录，重复/差异/重叠在预览显示。分享与文件打开仅接受 content URI；接收网页地址的分享不会自行下载或上传。

解析结果在导入预览、保存前共用课程字段排版：名称、教师、地点、备注补齐中西文边界空格，课程末尾级别及教室、楼层编号分别处理，时间、周次及网址不改写。已有课程只在界面、通知、小组件与可视化导出时格式化；原存储记录及可重新导入的数据导出保持不变。文字测量使用最终显示内容。

导入页的校区入口打开内置 `WebView`，提供网页后退、前进、刷新和关闭。顶层导航与下载地址限制为 `bnu.edu.cn`、`bnuzh.edu.cn` 及其子域的 HTTPS 默认端口，拒绝 URL 内认证信息。网页启用 JavaScript、DOM Storage 与 Cookie 以供学校页面使用，关闭文件/content 访问、混合内容和自动新窗口；TLS 错误直接取消。浏览器保存和恢复页面历史，关闭后返回导入流程。

`CampusResponseCapture` 在 WebView 消费响应前接管已确认的导出 GET：公开脚本使用的 `/frame/excel?method=download`，以及 XLS、XLSX、CSV 文件路径。文件直接使用首次响应写入缓存，避免一次性下载被再次 GET 后得到空文件；普通 HTML/JSON 响应保留原始流返回 WebView，重定向交回实际目标地址，维持正确网页来源。登录和其他 POST 不拦截。未接管的普通下载继续使用 DownloadListener。

传输从 CookieManager 按当前目标 URL 获取 Cookie，保留浏览器 User-Agent、有效请求头和 Referer。每次重定向重新检查目标及 Cookie，最多 8 次；连接与读取各 15 秒、总时限 90 秒、文件上限 15 MiB。文件先写缓存临时文件，完整接收后才经 FileProvider 送入解析与预览流程。下载可取消，失败、取消和已消费文件均清理缓存；下载本身不写正式课表。同校域默认端口的旧 HTTP 导航或重定向先升级 HTTPS，服务参数的百分号编码保持原样；直接 HTTP 下载仍拒绝，TLS 错误不放行。

文件名按有效响应头、官方导出链接的 `title`、正常 URL 文件名的顺序读取。学校公开导出脚本将 `title` 做两次 UTF-8 百分号编码，解码仅对受支持的学校导出端点启用；无法恢复的名称使用中性 `timetable` 和 MIME 后缀。已删除正文标题猜测、乱码年份拼接与文件内容猜后缀。有效原名经路径、控制字符和 UTF-8 字节长度检查后使用。

`blob:`、`data:` 下载不在支持范围内，可通过本地文件入口导入已保存文件。普通 HTTPS 下载、真实解析与预览保存流程，以及内置 WebView 的历史验证范围见 [1.3.0 迭代验证](迭代验证-1.3.md)。1.8.0 已实际登录珠海教务并执行列表检索和原生导出点击；默认学期的生成接口返回 HTTP 200、业务状态 400，未发起文件下载。当前下拉选项未匹配到用户指定的 2026–2027 秋季学期，因此本轮没有真实文件可供名称核对，详见 [1.8.0 验证记录](迭代验证-1.8.md)。

## 界面与视觉

今天、课表、方案、设置四个入口，单一当前方案。手机使用底部导航；窗口宽度达到 600 dp 使用左侧导航并移除底栏，达到 840 dp 展开侧栏文字；窗口变化保留页面与草稿。四页由 `HorizontalPager` 承载，点击导航采用共享的 `AppMotion.pageSpring`，手势滑动与标题、选中状态保持同步；重复快捷入口和快速连续导航保留最终目标。导入和导出草稿分别保存，翻页或重建页面不会丢失未提交内容。

顶栏直接显示页面大标题，在状态栏安全区下保留 26 dp 顶部间距。今天和课表的学期选择统一由“方案”页管理；待排与添加课程入口放在顶栏，“更多”收纳管理课程、导入与导出。各页独立包含固定高度的顶栏，标题、操作按钮和正文随同一个 pager 横移；底栏或侧栏保持固定。每页只处理自己的系统顶端留白，非当前页的动作不接收点击。点击导航前或主 pager 开始横向拖动时清除输入焦点并收起键盘，防止旧页的输入框将 pager 拉回；草稿继续保存在页面状态中。页面内纵向滚动及课表表头切周使用各自手势源，不触发这条页面离开处理。底栏在实测图标中心之间绘制单个胶囊，用 pager 连续位置同步横移，点击切换沿用非线性弹簧。

课表的“第 X 周”、日期范围及周切换按钮放在页面内，与顶栏分开。周切换栏和日期栏消费横滑切周，正文区域保留原有页面切换及滚动。顶栏图标使用 48 dp 触控区域与 4 dp 动作间距；周课表外侧各 12 dp、各天列间 3 dp。星期与日期行固定，课程及时间轴单独纵向滚动，极窄屏下表头和内容共用横向滚动位置。界面休假底色透明度为 0.03，列斜线为 0.075，课程斜线在原值上乘以 0.6。文字、图标及系统栏跟随主题。

七列均分正常视口，仅约 300 dp 以下的极窄屏可横向滚动。`TimetableAxis` 接收最终显示分组的起止跨度，全周共用时间坐标。1.12 将原平方根高度下限改为 Softplus：常规字号下 m=64 dp、k=1.6 dp/分钟、s=8 dp，基础时间刻度也使用同一 k。100 分钟的基础高度约为 160 dp，较长课程接近正比。算法先满足每个显示块的下限与时间顺序，再按需校正较长块严格更高；校正过大时选择满足约束的统一比例方案。课程高度仍为 y(end)−y(start)，首尾和时间轴对齐，连续课程内部课间计入跨度，无课长间隔压缩。多个短课共用同一段时间时，对齐约束可能使长块高于基础曲线，例如两个 45 分钟短课与 100 分钟块同轴时，后者约为 165 dp。

今天页单独使用按时间排序的单列布局，日期只在页面上方出现一次。左侧展示起止时间，右侧宽课程块依次放置名称、地点和教师；空白时间压缩，块内不重复时间。先测量完整课程文字，再使用与课表共享的 Softplus 时长曲线：H(t) = m + s·ln(1 + exp((k·t − m) / s))。常规字号下，今天页 m=76 dp、s=2 dp、k=84/两节课分钟数；默认两节 100 分钟约为 84.036 dp。两节时长继续来自当前学期作息，包含短课间、排除长休息。曲线使用简单系数，不反求参数，也不单独硬设 100 分钟分支。短课适度压缩纵向留白，文字下限和逐时长至少一个物理像素的修正保证完整内容与严格递增。大字号沿原参考高度缩放。独立单列不沿用时间坐标，因此不插入午休等大段空白。原始授课记录、状态绘制和详情选择继续复用统一课程模型。

时间栏展示节次及起止时间，课程块不重复时间。卡片优先为课程名和地点分配空间，剩余高度再显示教师；时间保留在左侧轴中，字段按课程名、地点、教师顺序排版；放不下的内容可在详情中完整查看。普通课程无边框，非本周课程使用淡色填充与彩色虚线，休假课程使用清晰的斜线阴影；不额外添加停课、非本周或节假日图标。位置重合时使用分组入口，不增加星期列宽；只有实际冲突才显示“同时段的课程”，跨周位置重合显示“课程安排”。详情使用原生 `ModalBottomSheet`，通过手势或系统返回关闭；连续周次显示为 `1–4` 等范围，原始周集合不变。

`AppIllustration` 以 Canvas 绘制 PLANNING、REST、IMPORT 三类平面场景，分别用于建立课表、空闲状态及导入入口，颜色来自当前 Material 主题。插画为装饰内容，功能按钮继续使用可识别图标。主页面与周切换采用弹簧动画；`ModalOrigin` 在点击时保存触发控件的屏幕位置，`AnimatedAppDialog` 据此展开窗口，关闭时沿同一路径收回，退出完成后才执行后续操作。外部文件和快捷入口使用无来源的默认动效。课程详情、课程组与待排列表保留原生底部面板，发起控件在关闭后平滑恢复底色。自定义弹窗在自身窗口的返回分发器中接收预测性返回进度，取消手势后回弹；教务网页有历史时先回退网页，关闭浏览器后返回保留在下层的导入页。实现参考 Android 官方的 [Compose 动画配置](https://developer.android.com/develop/ui/compose/animation/customize) 与 [预测性返回](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)。

弹窗在展开、收回及预测返回期间以约 28 dp 的屏幕可见圆角为目标，并按当前缩放比例补偿局部裁剪半径。全屏页面接近稳定位置时将圆角平滑归零，关闭时反向恢复圆角；普通弹窗保持圆角外形。

日期与时间字段调用 Material `DatePicker`、`TimePicker`；月份和周次使用 Android `NumberPicker`。选择器读取应用语言，确认后才写回编辑草稿，取消保持原值。导出页的选择器与视图粒度对应：日视图选择日期，周视图选择教学周，月视图选择月份，学期视图选择学期及其方案。

“设置 → 关于”打开独立全屏页面，以应用图标作为视觉焦点，平面日历与笔记本 Canvas 插画淡化为背景。页面显示运行时版本、作者主页、旧 Crid 起源链接、MIT 协议和第三方致谢；内容宽度受限并支持滚动与大字号。作者链接仅在点击后打开，协议全文随应用打包，可离线阅读。

应用图标采用实心日历纸面、紫色页眉与两处装订，五个紫色、青绿和暖珊瑚色课程格分布在三列中。彩色前景固定居中，背景资源随系统浅深主题切换；monochrome 图层保留同一外轮廓，以对应课程格留白呈现结构，由支持主题图标的启动器着色。图层采用 108 × 108 坐标，前景位于半径 33 的中心安全圆内；验证外轮廓一致性、课程格位置及内部颜色／透明度。设计依据 Android 官方的 [自适应图标说明](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)，裁剪及动效由系统启动器处理。

简体、繁体、英语可手动选择；系统语言不受支持时界面回退英语并禁用对应跟随选项。用户选择的语言保持优先。

今天页以课程开始时间的 12:00 和 18:00 划分上午、下午、晚上，跨界课程完整保留在开始时段。1.10.1 起仅传入当天实际授课记录，隐藏没有课程的时段；全天实际无课时以 REST 平面插画替代课程区域。休假停课和非本周记录不占今天页时段，课表页仍保留原有状态展示。已经结束的实际课程继续显示。全部展示课程先统一测量块高，再分段布局，保留跨时段的严格时长单调关系及原课程索引。

今天页顶部根据实际授课安排展示当前状态和下一节课，包含课程名、时间及地点；取消和非本周记录不参与状态计算。前台时钟刷新状态，返回前台立即重新核对。1.10 移除文学摘句、随机队列及轮播计时器；[摘句目录](今天页文学摘句来源.md)仅作为 1.9 历史记录保留。

1.10.1 在当天 EMPTY 和 FINISHED 状态下使用简短关怀作为摘要主标题，分别为“今天，留一点时间给自己”和“今天的课程已结束，放松一下吧”，提供简体、繁体与英语版本，末尾不加句号。日期预览不显示这两句当天文案；课程数量及下一节课信息继续保留。

课程详情、课程管理及待排列表共用 `AppBottomSheet`。顶端安全区固定放在面板外层，内容只消费水平和底部留白，使展开位置不再随面板高度反复变化；保留原生拖动、快速上甩、下拉关闭及遮罩点击行为。

## 自动广色域

支持条件包括有效显示器、硬件加速，以及显示器和当前配置均报告广色域能力。满足条件时自动请求 `COLOR_MODE_WIDE_COLOR_GAMUT`；否则使用普通窗口颜色模式。背景与课程颜色按色彩管理转换为 Display P3，保持原有配色及标准亮度。实现依据 [Android 广色域说明](https://developer.android.com/training/wide-color-gamut)。

`WideColorDisplayProvider` 监听显示器和前后台变化。弹窗使用自身窗口的显示能力；共享窗口通过引用计数保存原颜色模式，最后一个使用者退出时恢复。主界面和小组件配置页直接使用普通 `MaterialTheme`，没有独立的增亮主题层。导出和启动器托管的 RemoteViews 保持原有颜色路径。

1.11 完整移除 HDR 控件：设置项、模型属性、显示能力检测、动态范围监听、窗口 headroom 请求和曝光计算均已删除。`Settings` 使用 `@JsonIgnoreUnknownKeys` 读取旧版本的遗留首选项；写回时仅保存当前字段。`AppRepository` 仍使用严格 JSON 解码，学期、方案和课程中的未知字段继续被拒绝。原有 HDR 实现和测量结果仅保留在历史版本记录中。

## Android 集成

原生 RemoteViews 今日组件支持 2×2 当前／下一门卡和较高的当日列表；周组件以可读课程内容确定最小尺寸，默认以 4×5 添加；最小宽度 245 dp、最小高度 280 dp，过小实例提示放大。根布局内容留白为 16 dp，课程卡左右为 12 dp，最低高度卡片上下为 6 dp，其他紧凑卡上下为 8 dp，完整日程卡上下为 12 dp。日期主标题为 20–22 sp，状态同行；今天组件普通字号下的双栏断点为 300 dp，并随字体增大。周组件保持按日列表，宽度足够且字体正常时增加七日快捷入口。布局依据启动器的实际尺寸匹配信息档，同一档位共用一份 RemoteViews，避免重复打包大型列表；单列或完整今日日程最多 36 门，溢出提供剩余课程入口。宽版按两列排版，周预览随高度增加每个日期展示的课程数。内容使用受支持的 ListView，长文本优先保留地点，教师显示在地点下方。单日点击携带独立日期路由，恢复实例时先快照再替换主题键，覆盖旧新 ID 重叠情况。桌面快捷方式进入今天、课表及导入。参考来源见 [小组件设计](小组件设计.md)。

课程提醒一次向 AlarmManager 预登记最多 64 个不同触发时间，每个时间使用独立、不可变的 PendingIntent；同一时间的多门课程共用一次唤醒，分别展示通知。候选日期从授课周次或明确日期推导，并加入调休日期，覆盖长假后的课程且避免逐日遍历任意远的学期。每次刷新先登记新安排，再撤销旧安排，临近触发时不先清空闹钟。精确提醒获准时，普通模式使用 `setExactAndAllowWhileIdle`，用户选定的闹钟级模式使用 `setAlarmClock`；未获准或授权在调用时变化则使用 `setAndAllowWhileIdle`，界面显示尚未生效或可能延迟。系统下一闹钟入口返回今天页。[Android 闹钟说明](https://developer.android.com/develop/background-work/services/alarms)

应用持久保存已登记时间。刷新时，仅对已登记、已经到点且尚未下课的课程补发；发送前重新核对当前方案、提醒偏移与节假日。已送达身份由方案、课程及本地日期和时段等字段生成，独立于触发时间戳，时区变化不会让同一堂课重复弹出；记录持久保存用于去重，早于七天前日期的记录会被清理。关闭提醒、删除或调整课程以及切换方案后，刷新会撤销失效闹钟并清理本应用课程通道中已失效的可见通知。

开机、应用升级和系统时间变化通过广播恢复安排，精确提醒授权恢复及应用回到前台也会重建。即使本地登记表相同，恢复时仍向系统重新登记，以处理系统已清空闹钟的情况；升级时撤销旧版本的单闹钟身份。WorkManager 保留每六小时的有限维护与每日节假日同步，应用按实际课程时间唤醒，无常驻前台服务。

提醒设置界面分别读取通知总开关、课程通道与精确提醒授权，并展示系统是否明确限制后台。电池优化豁免状态单独说明，不能据此判断厂商自启动设置。用户可主动打开公开的 Android 通知、课程通道、精确提醒、电池优化列表或本应用详情页，并查看对应厂商的官方设置帮助；应用保留用户选择的静默通道设置。通知总开关或课程通道关闭时取消课程提醒，返回前台或授权回调后重新检查并调度。系统休眠仍有触发频率限制，厂商的后台限制和强行停止也会影响送达。[Doze 说明](https://developer.android.com/training/monitoring-device-state/doze-standby)、[后台限制](https://developer.android.com/topic/performance/background-optimization)、[强行停止后的 PendingIntent 行为](https://developer.android.com/about/versions/15/behavior-changes-all#stopped-state)

Direct Boot 使用独立接收器和设备加密存储。首次解锁前只读取最多 64 个触发时间对应的必要通知快照；快照按课程本地开始时间和提前分钟数在当前时区重算，保留跨夏令时的实际提前时长。发送记录与普通路径共用，迁移旧记录后防止解锁时再次通知。课表持久化前同步使快照失效，发布状态后更新修订标记，过期的异步刷新不能将旧课程写回快照。锁定路径不初始化完整仓库、凭据、WorkManager 或小组件。完整策略与厂商依据见 [提醒送达设计](提醒送达设计.md)。

## 导出

可视化导出复用排课引擎与 `displayCourses`，PNG 和 PDF 共用页模型与绘制坐标。一天、一周、一个月或一个学期各生成一页；月与学期页拼贴周课表，完整源授课记录及待排记录放在同页底部。多学期导出为每个学期选择一个方案，PDF 合为一个多页文件，PNG 每页输出一个文件。

导出时间轴兼顾文字所需高度与起止时刻对齐，并在同一页的所有课程之间保持严格的时长顺序。课块依次显示课程名、地点与教师，时间统一放在左侧轴中；页底详情逐项保留原始周次和对应教师，也保留各记录的起止时间。生成标签跟随应用语言，课程等源文本保持原文。普通课程采用淡色填充，仅非本周课程添加虚线，休假保留斜线阴影。页数按所选单位计算，预估与实际输出共用测量过程；PNG 倍率只改变采样。SAF 提供目录写权限，失败或取消后尝试清理本次创建的文件。画布资源预算见 [导出设计](导出设计.md)，已完成的导出实测见 [1.4.0 迭代验证](迭代验证-1.4.md)；1.5.0 沿用该导出契约并更新共享淡色。

可重新导入的 v1 JSON 仅包含方案名、课程身份、颜色、课程属性及授课安排，不携带学期日期、作息、应用设置或凭据；重新导入仍选择目标学期与写入模式。
