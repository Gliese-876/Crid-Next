# Crid Next 1.1.0 迭代验证

日期：2026-09-27。

## 本次变化

- 顶栏直接显示今天、课表、方案或设置的大标题，移除品牌文字和页面内重复标题；常用操作采用随主题着色的图标，并保留 48 dp 触摸区域、提示与无障碍名称。
- 手机周课表七列均分可用宽度，冲突课程不扩大列宽。仅内容视口不足276 dp（完整页面约300 dp）时开放横向滚动；普通手机与平板宽度不发生横向滚动。
- 左侧参考 [WakeUp 官方时间轴说明](https://www.wakeup.fun/doc/main_interface.html)，展示节次、对应上课和下课时间，课程块不重复时间。完整时间仍保留在详情和无障碍描述中。
- 统一每分钟高度系数绘制课程。压缩没有任何课节或课程覆盖的课间空白；跨节、跨午休的连堂课保护内部时间跨度，不因压缩而缩短磁贴。重叠安排以角标和详情列表呈现。
- 图标具有主题配色及 Android 自适应单色资源，浅深主题背景分别配置。平板仍使用侧栏且无底栏。

四份文件的 `ParseResult.valid` 均为 true，不需要用户勾选排除已明确待排的记录。原始 XLS 文件保持不变，逐字段预期与独立定向测试同步更新。

“合成课课课未”原始时间字段有四段：9–10周星期五9–10节、11–13周空时间、14–15周星期五9–10节、16周空时间，教师为示例戌。现在四段均保存，两个空时间段表示为 `Lesson.unscheduled=true`，保留周次与教师；不编造星期或节次，也不产生虚假课程提醒。

教师优先与原始授课段一一对应；同一周段跨多个星期且名单与不同周段数量相符时复用对应教师。无法唯一匹配的原名单保留在附加信息，具体教师标为待确认。例如合成课辛BⅡ为2位教师、3个不同周段，源文件不足以确定哪位教师重复；不循环套用、不把整份名单重复挂在每一段。

待排安排可在方案上下文的时钟角标与课程详情查看；v1 数据文件往返完整保留。PNG/PDF 将所选日期涉及教学周内的待排记录列入独立清单，保留其完整周次和教师，不归到虚构日期；范围外记录不列入。
