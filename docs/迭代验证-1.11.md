# 1.11.0 迭代验证

本轮调整方案页配色、移除 HDR 控件，并统一今天页与课表页的课程高度计算。最低 Android 12，自动 P3 广色域保留。

## 界面

方案页的学期与课表方案使用统一的灰紫色阶。未选中卡片使用低层级表面色，选中卡片在表面色中混入少量主题紫色；文字保持普通表面文字色，单选指示器承担明确的选中提示。配色变化使用弹簧过渡，原有圆角、留白及操作入口保留。

今天页复用课表的 `readableCourseHeight` 时长曲线，并以两节连课的原高度重新标定：常规字号下为 `60 + 24√(分钟 / 两节课分钟数)` dp，默认两节 100 分钟保持 84 dp。混有短课和长课时，正常内容的两节课仍保持同一高度。基准根据学期作息计算；全文测量、大字及物理像素排序需要时扩展高度。短课程只适度减少纵向留白，全天较长课程严格更高、同样时长等高，空闲时间不产生大段留白。空时段隐藏、无课插画和用户指定的状态文案保持不变。

## HDR 移除

删除 HDR 设置项及持久化属性，移除能力检测、监听器、窗口动态范围请求、曝光渲染和专用控件封装。主界面与弹窗使用普通 Material 主题，P3 根据显示能力独立启用。

旧版本课表中的首选项由 `Settings` 局部忽略未知键，保存时不再写回已移除的字段；学期、方案和课程仍按严格 JSON 校验。历史记录及用于验证旧文件兼容的测试样本保留，不参与产品功能。

## 验证

本轮 418 项去重检查通过：核心 JVM 190 项、应用 JVM 186 项、相关 Android 方法 42 项。Android 12 完成 38 项、Android 15 完成 14 项，同一方法多设备或重复运行只计一次，无失败或跳过。Debug lint 为 0 错误、42 条警告和 1 条提示，应用崩溃缓冲区为空。详细范围见 [QA 汇总](../artifacts/qa-v1.11/QA-SUMMARY.json)。

高度检查覆盖默认两节课独立展示和 45／100／180 分钟混排、不同作息、1／2／3 倍屏幕密度、较大字号，以及相差一分钟的严格像素排序。正常内容下两节课仍为 84 dp；长文案完整显示，同样时长等高。

生产源码、编译类和 debug APK 的应用自有 Dex 类已独立检查，无 HDR 类、旧设置字段、曝光或窗口 HDR API 残留，见 [移除审计](../artifacts/qa-v1.11/HDR-REMOVAL-AUDIT.json)。PNG 文件格式的 `IHDR` 块属于标准图像结构。旧 `hdrControls=true` 设置通过真实仓库读写回归，课表内容保留，保存后不再写回旧字段；未知的根数据和课程字段仍严格拒绝。

原 HDR 图标蒙版着色机制随功能删除，关于入口恢复原生 Material 图标，浅深色的颜色与五个课格孔洞通过实际截图验证。此前针对已删除机制的合成 P3 输入失败保留为历史诊断，不计为通过项。自动 P3 的窗口策略及背景、课程画刷仍通过独立回归。Android 15 初轮系统栏测试曾受 SystemUI 自身 ANR 弹窗影响，恢复系统后原方法全部通过，未修改产品系统栏逻辑。
