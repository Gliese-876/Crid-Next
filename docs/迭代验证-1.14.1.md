# 1.14.1 迭代验证

> 历史验证记录：本文描述当时的版本与检查结果。当前版本见 [README](../README.md) 和 [更新日志](../CHANGELOG.md)。`artifacts/`、`tools/local/` 路径及旧提交号属于未公开的本地开发记录。

本轮调整短提示和换行，最低 Android 12、目标 Android 17。

小组件的“今天的课程已结束”改为“今日课程已结束”；今天页使用同一状态标题，下方独立显示“放松一下吧”，未开始状态改为“今日课程尚未开始”。“今天，留一点时间给自己”保持原文，简繁中文同步处理。

创建学期提示缩短为“创建学期，安排课程”，尺寸不足时提示“请放大小组件”，在小尺寸和大字号下可按“请放大／小组件”分行。英文使用“Choose a timetable”和“Today's classes are over”，明确课表对象和今日范围。

今天页状态摘要及共用居中空态的标题、说明采用原生均衡换行。小组件保留已有的 balanced 换行和真实字体测量；大字号下优先完整显示文字。未插入固定换行，也未缩小字号或截断短提示。

核对断行时发现，将状态和关怀语放在一个标题里仍会出现“结／束”的断词，因此将它们分层显示。原生断行策略参照 [Android 文本排版文档](https://developer.android.com/develop/ui/compose/text/style-paragraph?hl=zh-cn)，效果以实际中文行内容为准。

当前课程与下一节之间已有分隔，倒计时位于下一节的课名、时间地点之后，保留“还有……”。其他日期的预览使用完整日期、“当天／这一天”和“首节课”，不会显示今天的倒计时。

## 验证

13 项状态单元测试、7 项相关 Android 界面测试通过，Debug lint 为 0 错误、56 条警告及 1 条提示。界面检查覆盖简繁中文及英语、280／360 dp 状态卡、方形和宽版小组件、真实系统 100%／200% 字号。保留既有课程边界和空态行为检查，并核对全文、裁切、末行孤字和关键中文词组的断点。

在 Android 12 的 200% 系统字号下，280 dp 卡片可用文字宽度为 496 px，结束标题宽 490 px、关怀语宽 290 px，两者均完整单行。未开始标题按“今日课程／尚未开始”分行，无课提示按“今天，留一点／时间给自己”分行。最小小组件的放大提示按“请放大／小组件”分行。

最终截图和每行像素记录见 定向验证产物（`artifacts/qa-v1.14.1/api31/final/`）。正常字号下 22 sp 标题实测为 44 px，200% 系统字号为 70 px；测试同时核对系统配置和实际文字尺寸。
