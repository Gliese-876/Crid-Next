# 1.14.0 迭代验证

> 历史验证记录：本文描述当时的版本与检查结果。当前版本见 [README](../README.md) 和 [更新日志](../CHANGELOG.md)。`artifacts/`、`tools/local/` 路径及旧提交号属于未公开的本地开发记录。

本轮优化课程详情和管理课程布局，为小组件补充空态插画、完整点击区域及 2×2 方形外观。最低 Android 12，目标 Android 17。

## 课程详情与管理

整门课程的编辑、删除文字按钮独立置于顶部右侧，课名使用完整宽度，学分放在标题下方作次要说明。单条源记录与所选课程的身份、时段一致时，日期、状态和时间融入同一张安排卡，避免重复大段信息。多条记录或连续课聚合保留“本次课程”的完整时间和地点，下面仍可查看每条原始授课安排。调休时保留原定星期或日期。

安排卡提高与弹窗底色的层次差异，时间、地点、教师等值统一使用 bodyLarge，标签弱化并对齐。卡片可用宽度不足 280 dp 或字号超过 1.3 倍时改为上下布局。所有长内容可以换行，周次继续使用自然范围。编辑、删除仍指向原课程 ID 和记录索引，确认范围及来源动画保留。

管理页的标题与新增入口协调排列。课程卡最多预览两组日期／星期、时间和地点，按完整组合去重，原始安排数量不变；待排记录不生成虚构日期。其余安排通过整卡进入详情，空列表保留新增入口。

## 小组件

无课时显示窗边书本、茶杯与植物；当天紧凑摘要的课程全部结束时显示收好的书包和合上的书；未选学期或方案时显示准备课表的场景。三类插画均使用原创 VectorDrawable，提供浅深主题版本。紧凑方形采用上下排列，宽矮布局采用左右排列；根据实际 XML 字体、换行和内边距测量正文，图片使用剩余空间。大字号及空间不足时优先完整文字，采用原生 balanced 换行避免末行孤字。

已有完整当日日程仍显示历史课程；周组件真正无课程时使用空态，保留原有非本周及停课记录的显示设置。过小组件继续优先显示放大提示。

启动器提供 dp 尺寸而非当前网格数。紧凑且长短边比不超过 1.25 的今日组件按近方形档处理：透明外层内居中放置等边圆角背景，边长取宿主短边。普通字号的单门课程填满内容区；宽矮双栏、高日程和周组件维持原比例。响应式映射保留所需实际边长，并避免方形候选抢选宽矮或高日程档，最多保留 16 个变体。

背景与内容容器提供打开应用的默认入口，课程和日期保留具体路由。ListView 按实际内容测量，长列表受内容区高度限制并继续滚动；短列表下方由父容器接收点击。行间距放入可点击行内，双栏间隙及较短列底部也有对应入口。没有用覆盖层拦截滚动，也没有给 AdapterView 设置不支持的普通点击监听。

## 验证

本轮 474 项去重检查通过：核心 JVM 190 项、应用 JVM 215 项、Android 12 上的相关界面检查 69 项，无失败或跳过。重复运行只计同一方法的最终结果，未重复执行本轮未修改的提醒、导出和付费服务流程。Debug lint 为 0 错误、56 条警告和 1 条提示，其中透明方形外层被提示为可精简父容器，该容器用于居中和重置尺寸。

详情检查覆盖普通单条、按周重复、待排、连续课、多个教师与地点、原始编辑删除目标及确认范围。管理列表核对预览配对、数量、空态与新增来源。浅深主题和中文、英语长字段均已检查；200% 字号使用实际系统设置，并断言真实渲染字号，早期仅覆盖 LocalDensity 的误标截图保留作诊断，不计为大字号证据。

小组件使用实际宿主测量及触摸事件，覆盖背景边距、插画、双栏间隙、较短列、行间距、列表尾部和日期入口，同时验证滚动不会误开应用。混合响应映射与重用保留正确形状和信息量；180×160 宿主中的可见背景为 160×160，左右各留 10 dp 透明空间，160×180、200×180、140×140 等尺寸也通过。最大传输体积为 858,676 字节，低于 900 KiB（921,600 字节）预算。

明细见 QA 汇总（`artifacts/qa-v1.14/QA-SUMMARY.json`）。最终截图保存在 详情与管理（`artifacts/qa-v1.14/api31/final/details/`） 和 方形及空态小组件（`artifacts/qa-v1.14/api31/final-square/`）。
