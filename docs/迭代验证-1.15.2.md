# 1.15.2 迭代验证

本次仅调整构建配置与发布校验，业务源码和界面资源保持不变。取消 ARM64 限制，恢复 ARM64、ARM32、x86 和 x86_64；最低系统仍为 Android 12。

正式构建使用 R8 优化代码并缩减未使用的资源，保留原生库的架构和 16 KB 对齐校验。发行目录保存对应的混淆映射，用于还原崩溃堆栈。配置依据 [Android 官方 R8 文档](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization)，采用适用于 AGP 9.1.1 的选项。

版本为 `1.15.2`，versionCode 为 `23`，由干净提交 `edcea38a78745efd1c9bbd6660cdf108d24503eb` 构建。正式 APK 为 4,231,512 字节，比 1.15.1 的 27,303,892 字节减少 23,072,380 字节，缩小 84.5%。

默认 Android 优化规则与依赖的消费者规则已合并。WorkManager 的工作类、ViewModel 构造器及序列化生成代码均由相应依赖规则覆盖；Manifest 组件与直接引用的小组件资源由构建工具识别。项目仅为 JXL 通过反射创建的默认日志类保留类名和无参构造器。

## 正式包操作验证

专用 Android 12 模拟器从 1.15.1 覆盖升级，课表及设置文件哈希不变，实际使用 x86_64 库。

一份原始 OLE XLS 经正式界面导入后得到 11 门课程、25 条安排，冷启动仍能读取。通过系统文件选择器导出的 JSON 可重新导入；除新建记录的 ID 外，所有课程字段一致。PNG 实际尺寸为 3824×5064，PDF 为一页且可读取文字。

课程编辑草稿在应用进程被系统结束后恢复，课名与学分均保留并成功保存。今日小组件通过桌面启动器实际绑定，浅深主题下均能显示课程。

维护任务在专用模拟器到期后实际构造并执行，WorkManager 返回 `SUCCESS`。验证期间仅调整该模拟器的时间且关闭网络，完成后恢复基线。桌面组件的空态插画与点击入口正常；关于页可打开完整许可文本。
