# 1.15.3 迭代验证

> 历史验证记录：本文描述当时的版本与检查结果。当前版本见 [README](../README.md) 和 [更新日志](../CHANGELOG.md)。`artifacts/`、`tools/local/` 路径及旧提交号属于未公开的本地开发记录。

课程详情在正常宽度下将课名与整课编辑、删除按钮放在同一行，按可见字形的视觉中线对齐。当前字体的字形边界与文本首末基线共同确定对齐位置，保留原生按钮和 48 dp 触控区域。学分单独显示在下方。窄屏或大字体下，标题使用完整宽度，操作紧随其下靠右；时间、地点、教师及周次等横排字段使用相同的文字视觉中线对齐，窄屏堆叠保留。

共享组件从原生文字排版结果读取实际首尾行，并用当前字体量取可见字形。文字组可向父容器传递整体边界，供标题栏、设置与选择项、导入导出、课程编辑、关于页及组件配置共用；日期圆形强调和原生按钮标签使用相同度量在现有空间内居中。普通正文、项目符号的基线和系统日期时间选择器保留原排版。

小组件的日期／状态标题、每日标题及居中空态文字使用真实 TextView 与排版结果测量。自然高度与固定高度分别计算上下留白，保留水平留白；调整后的标题高度参与空态图文布局。课程正文和导出课表的左上排版保持不变。

新增的两份 `.xls` 实际均为 GBK 编码的 HTML。列表模板支持“[课程号]课程名”和“上课时间、地点”表头，课程代码与名称分开保存。两个文件分别建立独立逐字段预期，不用另一份文件的教师信息回填当前文件。

作者与致谢采用“显示名(@用户名)”格式，显示名缺失时使用用户名。GitHub 公开资料中 ChiHuchen 未设置显示名，因此显示为 `ChiHuchen(@ChiHuchen)`，说明为“提供北京校区数据”，主页链接指向其 GitHub 账号；名单仍支持继续增加人员。

版本为 `1.15.3`，versionCode 为 `24`，保留多架构支持、R8 代码优化和资源缩减。
