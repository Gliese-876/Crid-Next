# 1.17.1 迭代验证

> 历史验证记录：本文描述当时的版本与检查结果。当前版本见 [README](../README.md) 和 [更新日志](../CHANGELOG.md)。`artifacts/`、`tools/local/` 路径及旧提交号属于未公开的本地开发记录。

2026-10-04，版本更新为 `1.17.1`，versionCode 从 `27` 增至 `28`。本轮调整导入窗口、全屏弹窗、更多菜单和底栏导航的动画衔接。原始证据保存在 本地 QA 目录（`artifacts/qa-v1.17.1/`）。

## 动画与交互

方案页顶部的导入按钮、空方案中的导入按钮分别捕获自己的 `ModalOrigin`。导入窗口沿实际点击位置展开，关闭时返回同一位置；来源位置失效时继续使用居中退场。

全屏窗口的入场弹簧采用临界阻尼，避免尺寸越过窗口边界后被裁剪。入场与退场交由同一 `Animatable` 接续，关闭动作改变目标时保留当前运动速度。全屏窗口清除默认背景变暗标记，让来源页面保持原有亮度；浮动对话框保留背景遮罩与原有弹簧规格。

更多菜单的动画状态在 Popup 外持有，展开、关闭以及快速反向切换均保留当前内容。管理、导入和导出动作在菜单完整关闭后执行，关闭期间的重复选择不会再次触发动作；切换页面会清除待执行动作。

底栏点击后通过 `requestedPage` 立即更新选中项；拖动时使用 `currentPage` 表示最接近的页面。拖动开始会取消尚未完成的点击导航，并清除请求目标，反向滑动能够直接接管选中状态。页面操作仍归属已稳定的页面。图标从原生导航项的 `LocalContentColor` 读取颜色，跟随 Material 选中状态渐变；选中胶囊继续跟随实际分页位置。

## 菜单实现与原生组件边界

项目沿用稳定版 Material 3 1.4.0。该版本的 `DropdownMenu` 固定使用组件内部的快速动效规格，没有公开的逐菜单动画规格入口。

菜单使用公开的 `Popup`、`MenuDefaults` 和 `DropdownMenuItem` 组合容器、样式及条目，动画使用 Compose 原生 `Transition` 和弹簧。窗口焦点、返回关闭和条目交互继续由这些组件处理，菜单高度受窗口约束并支持纵向滚动，定位兼容 RTL。依赖版本保持不变，全部调用使用公开 API。

`onClosed` 仅在实际打开过的菜单完成退场后通知一次。重新展开会中断尚未完成的关闭，页面失去交互资格时取消待执行动作，避免旧页面在切换后打开目标窗口。

## 设备动画验证

API 31 与 API 35 各 37 项动画和导航测试均已通过。测试覆盖全屏尺寸边界、入场中关闭、浮动对话框遮罩、真实导入入口、点击与拖动接管、菜单快速中断、返回关闭，以及 RTL 和大字号下的滚动选择。

动画测试使用 Compose 测试时钟，并按实际屏幕坐标观察动画中的窗口。完整 37 项执行在两台设备上均有 36 项通过；最后一项在验证新建原生底部面板可见性时仍冻结测试时钟。修正该同步后，三项菜单动作定向复跑全部通过，退出中的收缩、目标窗口尚未打开、关闭完成回调等断言保留。

前序测试还修正了窗口尚未完成组合时读取任意全局窗口、读取变换前布局框，以及冻结原生滚动所需时钟的问题。最终检查读取实际内容所属窗口和变换后的屏幕坐标；全屏无背景变暗的断言持续检查 90 帧。为结束阻塞的初始测试曾主动停止测试进程，该次运行的 `Process crashed` 终止消息不作为应用崩溃；最终崩溃日志另行保存。
