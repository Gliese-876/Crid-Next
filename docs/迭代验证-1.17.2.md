# 1.17.2 迭代验证

2026-10-04，版本更新为 `1.17.2`，versionCode 从 `28` 增至 `29`。本轮仅调整“更多”菜单的收放动效，其他弹窗入口与底栏导航沿用 1.17.1。

## 菜单调整

`AnimatedOverflowMenu` 使用触发按钮的真实中心作为动画支点，允许支点位于菜单边界之外。展开和收回围绕同一位置进行，收起和展开的目标比例分别为 `0.88` 与 `1`。

单个 Compose `Transition` 同时驱动尺寸和透明度。入场弹簧刚度为 `700`、阻尼比为 `0.9`，退场为 `1000`、`1`。透明度采用 `(progress / 0.35).coerceIn(0, 1)`，使菜单较早清晰出现，并在收回末段才淡出，突出朝按钮收放的空间变化。

菜单继续支持动画中断与反向衔接；管理、导入和导出仍在完整退场后打开，翻页会取消待执行动作。

## 功能验证

核心 JVM 177 项与应用 Debug JVM 230 项均通过，共 407 项；Debug lint 为 0 错误、57 条既有警告及 1 条提示。Android 15 / API 35 的 7 项菜单动画与 3 项菜单动作测试全部通过，用时 13.043 秒，崩溃日志为空。

新增逐帧用例以真实 48 dp 按钮中心为基准，比较菜单内部条目在展开与收回中段的屏幕坐标及缩放比例，确认两方向共用真实支点。原有退出回调、快速中断与重开、返回键、RTL 大字号滚动及三项菜单动作时序检查保留。

证据：[JVM 汇总](../artifacts/qa-v1.17.2/jvm-debug.json)、[构建日志](../artifacts/qa-v1.17.2/build-debug.log)、[10 项菜单设备测试](../artifacts/qa-v1.17.2/api35/menu-tests.txt)。

## 录屏检查

实际像素检查确认，收回时菜单顶部会越过展开后的顶部位置，向按钮移动，没有被 Popup 顶边裁切。初次录屏存在较长帧间隔；空闲复录捕获到连续的小尺寸、半透明入场帧，随后菜单显实并继续展开。保留原生 Transition 时序，无额外等待或计时器。

证据：[菜单操作录屏](../artifacts/qa-v1.17.2/api35/menu-transitions.mp4)、[空闲入场复录](../artifacts/qa-v1.17.2/api35/warm-menu-entries.mp4)、[入场逐帧测量](../artifacts/qa-v1.17.2/api35/warm-entry-measurements.json)、[顶部边界检查](../artifacts/qa-v1.17.2/api35/menu-top-edge-observations.json)。
