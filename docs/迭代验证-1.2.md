## 功能验证

### 跨周课程与课表布局

同名课程按归一化身份与 `displayCourses` 合并展示。教师、地点、周次和各自起止时间仍在完整授课记录中逐项对应，本周卡片按当前实际授课时长绘制。跨周同名记录不重复生成卡片，不把不同周的课程标成同时段冲突；同一天实际重叠的不同课程继续显示冲突入口。

设备回归覆盖 `crossWeekCourseUsesOneCardAndPreservesTeachers`、`onlyCurrentWeekOverlapsAreCalledConflicts` 和 `courseDetailsAndDurationRatioRemainAccessible`。手机七列课表适宽、时间只在左侧轴显示，以及平板侧栏与手机底栏之间切换且保留当前页，也均通过设备测试。

课程块去掉停课及非本周专用图标，依靠阴影与虚线表达状态。今天和课表不再重复展示方案名，保留学期入口与待排入口；待排记录继续保留源周次和教师，不生成虚构时间。

### 页面滑动与状态

四个主页面采用 `HorizontalPager`，支持手势与导航按钮平滑切换。`mainPagesSlideByGestureAndKeepLastNavigationTarget` 的最新通过结果来自 instrumentation-pager-draft-final.log（`tools/local/qa-v1.2/instrumentation-pager-draft-final.log`），覆盖滑动、连续导航的最终目标，以及辅助解析输入草稿在切页后的保留。页面重建及重复快捷入口回归也通过。

### 内置教务浏览器及导入

`campusPortalUsesEmbeddedWebViewAndReturnsToImport` 验证入口使用真实内置 WebView，并能返回导入界面。其最新通过结果来自 instrumentation-dialog-icon-recheck.log（`tools/local/qa-v1.2/instrumentation-dialog-icon-recheck.log`）。

`capturedCampusFileEntersCompleteImportPreviewAndClearsCache` 使用普通 HTTPS 校园下载请求和替身网络传输提供真实课表文件，随后执行真实下载文件处理、解析、完整导入预览、保存与缓存清理。`actualAndroidReadsAllSuppliedWorkbooksAndPersistsImport` 继续在 Android 上读取全部已提供样例并验证导入持久化。

这些结果验证了浏览器集成及下载到导入的数据链路，**没有验证实际学校账号的登录与下载**。内置下载仅支持允许的学校域名下普通 HTTPS 文件链接，`blob:`、`data:` 下载暂不支持；用户仍可保存课表后从本地文件导入。北京校区继续按与珠海校区同格式的既定假设处理。

### 关于、主题与应用图标

关于页以应用图标作为视觉焦点，日历与笔记本平面插画淡化为背景，无光晕或轨道。图标由日历装订环和多列课程格构成，彩色与 monochrome 版本保持一致造型。页面提供运行时版本、作者 Gliese-876 的主页、单独标注的旧 Crid 起源链接、MIT 全文及第三方致谢。第三方组件保持各自许可，没有统一声明为 MIT。

`aboutPageShowsAuthorMitAndThirdPartyLicenses` 的最新通过结果来自 instrumentation-about-calendar-icon-final.log（`tools/local/qa-v1.2/instrumentation-about-calendar-icon-final.log`）。启动器的自适应前景/背景、monochrome 图层及夜间背景由 `launcherIconSupportsThemedMonochromeAndNightBackground` 验证；显式深色主题下系统栏图标的可读性回归通过。

### 导出与既有功能

导出设备测试共 8 个唯一方法通过，覆盖日、周、月、学期四种视图，真实 PNG 与 PDF 画面对比，应用语言优先级，普通无边框及非本周虚线，多页完整性，图片采样分辨率，以及待排课程的教师与完整周次对应。

新增 `sameCourseAcrossWeeksExportsOneCardAndKeepsEachTeacherWeekPairWithoutFalseOverlap` 验证跨周同名卡片合并、各周次教师和地点对应、差异起止时间完整保留、实际时长不被拉长且没有跨周假冲突。最新通过结果来自 instrumentation-export-week-time-recheck.log（`tools/local/qa-v1.2/instrumentation-export-week-time-recheck.log`）。

凭据加密且排除在课表导出之外的设备回归通过。默认学期创建、四页导航、全部提供样例的 Android 导入与持久化等既有流程继续通过，逐方法来源可在最终汇总 JSON 的 `AndroidResults` 中查看。
