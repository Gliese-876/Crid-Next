# Crid Next 1.3.0 迭代验证

当前版本为 `1.3.0`，versionCode 为 `4`。本轮覆盖连续课程显示、课表高度与文字排版、固定顶栏、课程配色、平面插画、弹窗动效及启动器图标。首个正式发行版仍为 [v1.2.0](releases/v1.2.0.md)，其发布说明与验证结果独立保留。

## 执行状态

核心 JVM 119 项、应用 JVM 84 项及 Android 设备 31 项，共 **234 个唯一测试方法通过**。设备方法采用本轮各方法的最新结果；修正选择器和补充边界后，仅重跑受影响方法。Debug lint 为 0 错误、28 条警告，各轮崩溃日志为空。汇总见 [`tools/local/qa-v1.3/final-summary.json`](../tools/local/qa-v1.3/final-summary.json)。

设备为 API 36，编译及目标 SDK 为 API 37。系统栏的三项回归分别在三键导航、手势导航运行并通过，重复方法不重复计数。已检查正常手机宽度、320 dp、平板、浅深主题及三类插画；关闭系统动画时，弹窗关闭和返回正常。QA 的窗口、密度、动画比例和导航模式均恢复原值，主模拟器未改动。

## 连续课程与源记录

`Python程序设计` 的原始数据是一门课程、两条授课记录，分别为第 5–6 节和第 7 节；此前显示层按起止时刻拆成了两卡。`DisplayCourse` 现在将同一授课上下文的相邻节次合为一张 `13:30–16:15` 卡片，底层两条 `Lesson` 保持原样，无需迁移或重新导入。

连续节次合并要求课程身份、日期、周次、星期、教师、地点、备注及状态一致，节次相邻且时段不倒置。教师、地点、周次或状态变化，跳节或仅钟点接近时，不按此规则合并。跨周记录继续保留各自信息，并且不会扩大本周卡片的时间跨度。

新增回归覆盖原文件解析、首次导入与重复合并导入；显示测试检查输入顺序不影响结果、源记录不变及不同授课上下文保持独立。设备回归检查一张连续课程卡、教师位于地点上方、详情没有冗余关闭按钮，以及第 `1–4` 周的范围显示。

导出设备回归 `consecutivePeriodsExportOneCardWithOnlyTheTwoOriginalTeachingRecords` 覆盖日、周视图：一张卡片只显示一次合成总跨度，明细保留原来的两组教师、周次和地点，以及两条原始时间，不生成第三条授课记录或自身冲突。

## 课表高度与信息排版

`TimetableAxis` 以最终课程分组的起止点建立共用坐标。向前约束图先为各卡片保留阅读空间，再用全局校正保证任意较长卡片严格高于较短卡片；遇到会使轴过长的嵌套时段，选用更紧凑的统一比例方案。卡片始终按 `y(end) - y(start)` 绘制，首尾与时间轴一致。界面不要求所有高度严格等比例，导出仍使用全局线性比例并保留全文。

布局回归覆盖 1–1439 分钟的时长顺序、跨日期受嵌套课程影响的高度比较、连续课间、午休压缩、自定义早晚时间、大字号、相邻卡片边界及比例回退。高度差至少保留一个物理像素，1×、2× 密度取整后仍严格递增。七列课表的常规屏宽适配继续保留。

课程卡先为课程名、教师和地点各保留一行，再按文字测量结果分配剩余空间；教师始终在地点上方。新的 16 色调色板用于新身份，旧课程保存的颜色不重分配。文字按实际底色自动选择深色或浅色，共享色板在 343 种颜色与 8 种主题、周次及休假状态组合下，验证文字与底色、休假斜线的对比度不低于 4.5。休假保留斜线阴影，非本周保留虚线，普通课程无边框。

## 顶栏、插画与动效

今天和课表移除学期选择，学期及方案统一在“方案”页管理。待排入口固定在顶栏，课表页的周次、日期范围与周切换也固定显示。日期栏以实心主题色圆形强调今天，数字使用对应的高对比前景色，圆形直径受列宽约束。

`AppIllustration` 为规划、休息和导入绘制 PLANNING、REST、IMPORT 三类 Canvas 平面场景，沿用当前主题颜色。功能操作保留图标；关于页继续以应用图标为视觉焦点，其他插画作为背景。

主页面和周切换使用共享 Compose 弹簧动画。课程详情采用原生底部面板；全屏页面及确认弹窗采用空间进退场，退出完成后才移除窗口或执行后续操作，并接入弹窗自身窗口的预测性返回分发器。新增设备回归 `fullScreenDialogsKeepTheirContentUntilSpatialExitCompletes` 检查关闭过程中内容仍保留且发生位移或缩放，结束后才退出页面。

## 图标

彩色前景保持固定并居中，系统浅深主题只切换背景资源。monochrome 图层与彩色前景共用造型和变换，供启动器生成主题图标。108 × 108 坐标中，包含描边的保守半径约为 31.31，小于中心安全圆半径 33。

图标设备回归检查浅深背景不同、彩色前景像素不随夜间模式改变、彩色与单色轮廓一致、中心位置及可见描边的安全边界。

## 教务入口与导出响应

北京入口更新为学校 [教务管理服务平台](https://ss.bnu.edu.cn/)，地址来源见[教务部公告](https://jwb.bnu.edu.cn/docs/2025-04/3a889d3eba3a439e9d3e8cf5c8a4c320.pdf)。手机 User-Agent 实查发现学校跳转包含 `http://cas.bnu.edu.cn/cas/login`；应用将同校域默认端口导航升级 HTTPS，保留原服务参数编码，继续执行证书校验。最终原生 WebView 已显示统一认证及“教务管理服务平台”登录页，未输入账号。截图见 [`beijing-native-login-fixed.png`](../artifacts/qa-v1.3/beijing-native-login-fixed.png)。

针对珠海手机端“下载的文件为空”，下载器新增原始响应捕获。公开 `jkingo.noprint.js` 使用的 `/frame/excel?method=download` 和 XLS/XLSX/CSV 文件请求只发送一次，附件直接进入缓存和导入预览；登录及其他 POST 不拦截。普通 HTML/JSON 原流返回网页，重定向保留真实来源，Cookie 与 Referer 按目标处理；gzip、取消、大小限制和临时文件清理均有回归。

新增九项 JVM 用例与两项真实 WebView 离线用例，覆盖“第二次请求为空”的一次性响应、iframe 导出、逐跳重定向和普通页面透传。已验证该捕获机制；未在用户手机的已登录会话中重现其具体列表按钮请求，实际账户导出仍需手机端复测。课表样例继续沿用珠海来源，北京文件格式保持此前约定的暂定假设。

## 沉浸式系统栏

主页面、全屏页、确认弹窗、原生底部面板和小组件配置页统一采用 edge-to-edge。状态栏与导航栏保持可见、透明，关闭三键导航的额外对比遮罩；图标按所在背景和弹窗遮罩选择深浅。小弹窗及原生配置页保留系统安全区和键盘避让。`SystemBarsInstrumentedTest` 的三项双主题回归在两种导航模式下均通过。
