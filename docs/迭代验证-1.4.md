# Crid Next 1.4.0 迭代验证

> 历史验证记录：本文描述当时的版本与检查结果。当前版本见 [README](../README.md) 和 [更新日志](../CHANGELOG.md)。`artifacts/`、`tools/local/` 路径及旧提交号属于未公开的本地开发记录。

版本为 `1.4.0`，versionCode 为 `5`。本轮调整课程配色、标题位置、导出范围与页面组织、原生选择器及弹窗动效。此前结果保留在 [1.3.0 迭代验证](迭代验证-1.3.md)。

## 课程与界面

课程块恢复淡色，通过色相、明度差异提高区分度；新颜色分配同时检查浅、深主题的实际填色，避免淡化取整后相同。已有课程保存的颜色保持不变。课程身份不增加编号、图形或纹理；休假阴影及非本周虚线仍表达原有上课状态。文字继续按实际背景选择高对比深浅色。

顶栏大标题的上方间距调整为 26 dp。课程块按课程名、教师、地点排列，时间由左侧时间栏表达。

## 导出

日、周、月分别选择起止日期、教学周、月份。学期视图允许同时选择多个学期，每个学期分别指定课程方案。切换视图保留各自范围，保存请求使用当时选定的完整批次。

每页对应一个完整日期、教学周、月份或学期。月和学期用七列周课表拼接，学期外及该月外的单元格留空；同一日期不会因跨月重复。多学期 PDF 合并为一个文件，每学期一页；PNG 每学期一个文件。

页面根据内容扩展，课程及时间单位不拆页。课程首尾与所在周的时间轴对齐，整页跨周比较仍保证时长更长的课程块严格更高。冲突课程使用独立列道。课程块保留当天适用的教师和地点，各原始安排的周次、教师、时间、地点、备注和附加字段集中列在同页详情，待排记录也随对应单位保留。

## 选择器与动效

学期日期、作息时间及导出日期使用 Material 日期和时间控件；周次、月份与提醒分钟使用 Android 数字选择器。应用语言决定选择器语言，时间格式遵循系统 12/24 小时设置。日历在可用宽度达到 360 dp 时完整显示；更窄时使用同一官方控件的日期输入模式。选择器在弹窗内部再次提供应用语言，避免日期标题回退系统语言。点击确定时记录选择值，退出动画完成后提交；未修改学期日期或周数时直接关闭，避免自动推算改变原日期。

弹窗记录触发控件的位置，打开和关闭沿同一路径移动与缩放；来源控件消失或窗口配置改变时改用居中缩放。预测返回沿同一路径收回，取消返回手势后恢复。课程详情继续使用原生底部面板的拖动交互，来源课程块在关闭后恢复底色。

## 验证状态

核心 JVM 121 项、应用 JVM 97 项、Android 设备 48 项，共 **266 个唯一测试方法通过**。设备测试使用 Debug 构建；计数采用每个方法的本轮最新结果，针对修复重跑及两种导航模式的重复执行不重复计数。Debug lint 为 0 错误、33 条警告，最终崩溃日志为空。汇总见 final-summary.json（`tools/local/qa-v1.4/final-summary.json`）。

导出设备测试 13 项全部通过。真实 14 门课程、40 条安排展开为 684 条带日期记录及 2 条待排记录，完整输出单页 PDF、5616 × 7437 的 1 倍 PNG 和 11232 × 14874 的默认 2 倍 PNG；文件约为 2.01 MB、4.93 MB。原始安排在页底去重保留，所有课程及教师、周次、时间、地点的对应关系均通过检查。产物见 export-validation（`artifacts/qa-v1.4/export-validation/`）。

大图使用流式 PNG 编码，每条最多 128 行且不超过 1,048,576 像素，条带位图约 4 MiB；单张输出上限为 192MP。编码器独立验证 CRC、连续压缩流、多 IDAT 块、透明通道及取消行为。1 倍、2 倍流式图片分别与整页 Bitmap 逐像素比较，两档均只有 2 个像素存在不超过 2/255 的抗锯齿取整差异，所有条带边界均无差异。PDF 提取文本除 NFKC 外，仅为已确认的同形兼容部首“⻔／门”和“⺒／巳”增加测试归一化，保留完整文字与记录配对断言。

原生选择器 6 项、来源动效 5 项、导出范围界面 2 项通过。手工检查手机／平板与浅深主题布局，360 dp 日历七列完整；320 dp 官方输入模式支持有效日期确认、取消保留原值，并拒绝越界日期。系统栏 3 项回归分别在三键及手势导航下通过，键盘收起后恢复透明系统栏。截图与设备记录见 qa-v1.4（`artifacts/qa-v1.4/`）。

设备验证使用独立 API 36 模拟器；编译与目标 SDK 为 API 37。珠海已登录账户的真实下载链路仍按 [1.3.0 记录](迭代验证-1.3.md) 的验证边界报告，本轮不重复声明其通过。
