# Crid Next 1.5.0 迭代验证

> 历史验证记录：本文描述当时的版本与检查结果。当前版本见 [README](../README.md) 和 [更新日志](../CHANGELOG.md)。`artifacts/`、`tools/local/` 路径及旧提交号属于未公开的本地开发记录。

版本为 `1.5.0`，versionCode 为 `6`。本轮调整课程淡色、弹窗圆角，并加入自动 P3 背景绘制及可选 HDR 控件高光。此前结果见 [1.4.0 迭代验证](迭代验证-1.4.md)。

## 课程配色与 P3

浅色主题使用 16% 的课程色混合，低明度课程色使用 20%；深色主题将柔化后的课程色按 24% 混入背景。课程保存的颜色身份保持不变，休假斜线与非本周虚线沿用原规则。正文保持 SDR，导出和桌面小组件只共享淡色调整。

支持广色域的设备自动启用 P3 背景路径，HDR 开关不影响该选择。背景颜色经色彩管理转换为 Display P3 后，以原生 ColorLong 着色器进入 Canvas，保留原有圆角、裁剪和透明度。现有色板在转换前后保持相同的视觉颜色；该路径支持原生 P3 数据。

## 可选 HDR 控件

设置中的“HDR 控件”默认关闭。不支持的屏幕仍显示该行，并禁用开关。能力判定同时检查显示器和硬件加速状态、广色域支持、HDR 支持及 HDR/SDR 比率是否可用。

启用后，支持设备上的前台窗口请求 HDR 模式及 1.25 倍目标 headroom，局部高光按当前可用比率限幅。选中导航、日期圆点、主题选项和开关使用原生 Canvas ColorLong 高光，课程块保持淡色。主窗口、弹窗与底部面板分别观察所在屏幕，并在最后一个使用者退出时恢复窗口原状态。实现保持 Material 3 控件，屏幕整体亮度设置保持原值。

高光思路参考 [iOS 26 UIKit 的 HDR 颜色支持](https://developer.apple.com/videos/play/wwdc2025/243/)。Android 实现依据 [广色域窗口](https://developer.android.com/training/wide-color-gamut)、[HDR headroom](https://developer.android.com/reference/android/view/Window#setDesiredHdrHeadroom(float)) 与 [ColorLong 画笔](https://developer.android.com/reference/android/graphics/Paint#setColor(long))。

## 弹窗圆角

弹窗在展开、收回及预测返回时呈现约 28 dp 的可见圆角。裁剪半径补偿当前缩放，避免弹窗缩小时圆角一起缩小。全屏页面接近稳定位置时将圆角平滑归零，收回时沿相反过程恢复圆角；普通弹窗保留圆角外形。课程详情继续使用原生底部面板的拖动与返回行为。

## 验证结果

核心 JVM 123 项、应用 JVM 102 项、Android 设备 57 项，共 **282 个唯一测试方法通过**。设备测试使用 Debug 构建；同一方法修复后重跑只计最新结果。Debug lint 为 0 错误、34 条警告，崩溃日志为空。汇总见 QA-SUMMARY.json（`artifacts/qa-v1.5/QA-SUMMARY.json`）。

新增验证覆盖旧设置缺少 HDR 字段时默认关闭、偏好保存与并发合并、SDR／仅 P3／HDR 窗口策略、重复窗口使用者退出后的恢复，以及不支持设备上仍可见但禁用的开关。HDR 原生画笔在 F16 位图中保留约 1.25 的分量；原生 P3 绿色经同一着色器路径映射到线性 sRGB 时，红色分量小于 −0.15、绿色分量大于 1.02，确认颜色没有先被压到 ARGB。SDR 回退、透明度、课程淡色及圆角也经过检查。

动效的 7 项设备测试通过，其中两项在实际动画中段检查截图像素：内容四角确实被裁剪，圆角缺口保留足够宽度；全屏停稳、预测返回取消及退出回调均正常。另检查了实际“关于”和“导入”页面的进出场截图，以及手机浅深主题课表。图片见 root/（`artifacts/qa-v1.5/root/`）。

原有导出 13 项、课表与导航、原生日期选择、教务响应捕获及系统栏回归均通过。真实 14 门课程、40 条安排仍可导出为完整学期单页 PDF 和 1 倍／默认 2 倍 PNG。导出和桌面小组件沿用 SDR，仅同步本轮淡色调整。

设备为独立 API 36 模拟器，编译及目标 SDK 为 API 37。实际设备报告 HDR 类型为空、颜色模式仅默认模式、HDR/SDR 比率不可用；已确认 HDR 设置行显示且无法切换。测试后恢复尺寸、密度、动画倍率、导航模式、时间格式及亮度设置。

**物理 HDR／P3 显示尚未在支持设备上实测。** 模拟器上的窗口参数、浮点位图和截图能证明能力回退与绘制数据，不能替代真实屏幕的亮度、色域及屏幕切换测量。
