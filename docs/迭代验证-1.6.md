# Crid Next 1.6.0 迭代验证

版本为 `1.6.0`，versionCode 为 `7`。本轮将 HDR 从局部装饰改为全局控件色彩主题，并固定周课表的星期、日期行，减淡休假阴影。此前结果见 [1.5.0 迭代验证](迭代验证-1.5.md)。

## 全局 HDR 控件

已移除原有高光线及额外导航胶囊。按钮、导航指示、开关轨道、选择项、输入框和控件容器直接使用 `HdrControlTheme` 提供的语义色。颜色先转换到线性扩展 sRGB，再逐通道乘以曝光值；曝光随当前窗口可用动态范围变化，上限为 1.25，原始透明度保持不变。设计参考 [Apple 的线性曝光颜色接口](https://developer.apple.com/documentation/uikit/uicolor/init(red:green:blue:alpha:linearexposure:))。

同一颜色角色可能用于背景、文字或图标，因此按实际前景和背景限制曝光，文字对比保留 4.55 的余量，边界对比保留 3.05 的余量。普通文字及 `on*` 内容色明确保留 SDR；页面阅读背景、课程填色和课程信息也保持原有淡色。深色控件无需强行归一化到超过 SDR 白，较亮的控件填色通过完整绘制路径保留大于 1 的分量。

P3 仍在支持设备上自动启用，与 HDR 开关独立。HDR 默认关闭，不支持时设置项保持可见并禁用。主页面、弹窗和底部面板从同一原始主题计算各自窗口的颜色，避免重复曝光。显示能力监听、退后台撤销请求及窗口原状态恢复沿用前一版机制。

## 绘制框架与配置页

采用稳定 Compose BOM `2026.09.00`，Compose UI、图形、运行时与 Foundation 为 `1.12.1`，Material3 保持 `1.4.0`。新图形库的普通画笔及渐变支持长色值，能让 Material 控件直接绘制 HDR 颜色。普通文字和 `Icon` 的颜色滤镜仍有 ARGB 路径；文本按实际 SDR 结果进行对比校验，唯一使用颜色滤镜的关于入口图标改用原图透明度蒙版及长色值填色。

工具链同步为 AGP `9.1.1`、Gradle `9.3.1`，继续使用 JDK21 和 Kotlin `2.3.0`。Gradle 发行包使用官方 SHA-256 校验；新 AGP 显式保留 Debug 与 Release JVM 测试任务。版本和接口依据 [Compose 发布记录](https://developer.android.com/jetpack/androidx/releases/compose-ui)，实际 Maven 与源码核对材料保存在 `tools/local/compose-upgrade16/`。

小组件配置页迁为 Compose Material3，并复用相同的基础色板、HDR/P3 策略和安全区处理。配置选择可跨重建保留，仅保存时写入当前小组件；取消、返回及无效 ID 不写入。桌面上的 RemoteViews 仍由启动器绘制，保持 SDR。

## 固定日期与浅阴影

周课表的星期、日期行固定在课程区域上方，课程和左侧时间轴在同一容器中纵向滚动。极窄屏使用同一横向滚动容器包裹表头及内容，保持列对齐；正常宽度仍七列同屏。今天页保持原有滚动方式，周切换和课程详情交互保留。

日期列的休假底色透明度降为 0.03、斜线降为 0.075，界面课程块的休假斜线透明度乘以 0.6。非本周虚线和普通课程无边框规则保持；此次仅调整界面阴影，导出与桌面小组件的状态样式未改。

## 验证结果

核心 JVM 123 项、应用 JVM 107 项、Android 设备 66 项，共 **296 个唯一测试方法通过**，失败和跳过均为 0。设备测试使用 Debug 构建；重复执行不重复计数。Debug lint 为 0 错误、32 条警告，崩溃日志为空。记录见 [`final-summary.json`](../tools/local/qa-v1.6/final-summary.json)。

新增验证以真正的 Material 控件绘制树为输入，由 `HardwareBufferRenderer` 输出到先清空的 RGBA F16 目标，检查原生按钮、Tonal Button、FilterChip、开关、RadioButton、Checkbox、输入框、禁用状态、日期与时间选择器及嵌套主题。亮色控件本体保留大于 1 的分量；选择切换和双主题均通过，正文及禁用内容保持相应的 SDR 样式。另检查关于入口图标的长色值、透明度与蒙版形状。

小组件配置的 3 项测试覆盖保存、取消、系统返回、重建及无效 ID。固定表头的 2 项测试用真实滑动验证日期位置不变、课程和时间轴同量移动、课程仍可点击，以及 280 dp 极窄屏下表头与正文横向同步。原有 7 项圆角与来源动效、原生选择器、系统栏、导航和教务捕获回归均通过。

原有导出 13 项全部通过，220 份检查产物已取回 [`export-validation/`](../artifacts/qa-v1.6/export-validation/)。真实 14 门课程、40 条安排仍完整导出为一学期一页的 PDF 和 1 倍／默认 2 倍 PNG。

设备为独立 API 36 模拟器，编译及目标 SDK 为 API 37。已检查实际 HDR 禁用项，并对手机和平板的浅深主题课表做滚动前后比较。**物理 HDR 亮度、P3 色域及实际屏幕切换仍未在支持设备上实测**；浮点 GPU 渲染、窗口策略和截图不替代真实显示面板验证。
