# Crid Next 1.7.0 迭代验证

版本为 `1.7.0`，versionCode 为 `8`。本轮修复横向切页跳动，增加课程编辑、课表表头手势及自适应小组件，简化图标并扩展控件 HDR 层级。历史结果见 [1.6.0 迭代验证](迭代验证-1.6.md)。

## 导航和课程详情

顶栏不再随目标页面提前增减高度。页面标题跟随停稳的页面，今天日期及课表周切换、日期行分别留在各自页面内。两条课表表头消费水平手势，每次完成滑动切换一周；取消手势和点击不切周。课程正文保留纵向滚动及根页面横向切换，极窄屏仍可横向查看课表。

今天页使用独立的单列日程布局，不复用周课表网格。页面只保留一处日期，左侧显示起止时间，右侧宽课程块按名称、教师、地点排列，块内不重复时间。空白时段压缩处理；课程内容决定所需的最小高度，在此基础上仍保持时长更长的课程块严格更高。

详情中的日期、时间、教师、地点和周次均为同级信息行，内容使用相同字号、字重和行高。编辑与删除使用 48 dp 图标按钮，提供长按提示和完整无障碍名称。详情与课程管理列表使用原生底部面板，长内容打开后完全展开，可以下拉、点击外部或系统返回关闭。

## 手动管理课程

今天和课表顶栏提供添加课程及管理课程入口。管理列表按逻辑课程展示当前方案全部来源记录，包含待排、具体日期以及本周未显示的课程。编辑器支持课程名、学分、颜色和附加信息，每条安排分别保存周次、日期或星期、节次或时间、教师、地点及备注。

编辑目标保存打开时的原始记录快照；提交时在同一仓库锁内核对目标方案和记录。无关课程的新修改保持，目标记录已变更则保留草稿并报告冲突。保存经校验、原子写入后才发布状态。删除单条安排使用原始课程 ID 和索引，不使用用于显示的连续时段合成记录；删除某来源的最后一条安排时，仍存逻辑课程保留其学分和附加信息。

## 自适应小组件

今日组件默认 2×2，紧凑尺寸显示当前或下一门课程；较高尺寸显示当日列表。周组件在宽矮尺寸显示七日概览，在窄高尺寸显示按日课程列表。实际主机尺寸决定布局，最多保留四个响应尺寸变体；每个变体限制条目数并提供剩余课程入口。教师位于地点上方，长文本及大字号通过列表滚动访问。

组件使用 RemoteViews 支持的 ListView 和真实主机适配器；逐日点击携带独立日期与路由。旧新实例 ID 重叠的恢复先快照主题，再清理旧键并写入新键。刷新复用现有非精确 RTC 广播，选择下次课程开始、结束或午夜；实际触发受系统调度影响。桌面组件由启动器绘制，保持 SDR。

## 色彩和图标

共享控件容器使用阅读、辅助、抬升、聚焦、选中五级语义层次，应用到方案卡、导入结果、导出选择、详情与关于入口。可用 HDR headroom 上限提高到 1.5，曝光同时受实际文字对比限制。阅读背景、正文、边框及淡色课程块保持 SDR。RadioButton 和 Checkbox 所有动画状态在首次建立时使用同一线性色域，保留从 SDR 未选中到 HDR 选中的颜色分量。

图标简化为实心日历形状和三处课程格留白。彩色、单色图层使用相同轮廓；前景固定居中，背景随浅深主题切换。自适应安全区和轮廓一致性通过实际矢量绘制验证。

## 文案和学期填写

导入页使用“选择导入方式”，设置与导入统一称“AI辅助解析”。展示型短文案不加末尾句号。今天页提供 112 条三语言情感短句，按 14 种实际课程情境选择，周次位于摘要卡左上，课程数量通过右上图标显示，下一门信息单独显示。中间的大字短句不再重复数量和时间。随机轮播记住最近八条，前台停稳时每 20 秒切换；其他页面、弹窗期间和后台暂停，同一字体与宽度下保持固定高度。

学期日期按所选的周起始日填写完整周：周一至周日，或周日至周六。日期选择器只接受对应星期，原生输入模式也执行同一校验；起止边界和周数联动。历史数据不因打开或取消编辑而改写，编辑未对齐的旧学期时须先调整边界。课程编辑的新安排默认周次为 `1..学期周数`，原记录中的历史额外周次可保留。

## 教务下载文件名

两条下载路径共用文件名解析。合法的扩展参数优先，普通参数兼容 UTF-8 及 GB18030 百分号编码，按明确字符集严格解码；可逆的 UTF-8 响应头误解码保留单独恢复路径。参数优先级及扩展编码依据 [RFC 6266](https://www.rfc-editor.org/rfc/rfc6266) 和 [RFC 8187](https://www.rfc-editor.org/rfc/rfc8187)。

用户提供的名称含 `�`，部分字节在收到字符串前已被替换。完整下载后，若响应头、下载回调与链接均无有效文件名，应用从文件中的短课表标题或明确学年信息生成可读名称，通用回退为“课表”；不猜测丢失的学校或学期名称。原始文件内容保持不变，长中文和补充平面字符按 UTF-8 字节数截断并保留扩展名。

## 验证结果

核心 JVM 156 项、应用 JVM 159 项、Android 设备 124 项，共 **439 个唯一测试方法通过**，失败和跳过均为 0。重复执行不重复计数，修复后的方法结果覆盖前次失败。Debug lint 为 0 错误、38 条警告及 1 条提示。汇总保存在 [`final-summary.json`](../tools/local/qa-v1.7/final-summary.json)，对外副本位于 [`QA-SUMMARY.json`](../artifacts/qa-v1.7/QA-SUMMARY.json)。

新增验证覆盖原始课程快照与并发提交、同名来源元数据保留、草稿重建、真实仓库增删改、取消回到原详情／管理列表，以及实际按钮的弹窗起点。详情测试取得真实文本布局，核对时间、教师和地点的字号、行高及字重相同。课程记录操作始终使用原始 ID 与索引。

今天页测试检查独立时间轴、单次日期显示、课程块内无重复时间、严格时长单调、长文本及大字号。情感短句逐一在 Android 上验证三语言输出、场景边界、停止轮播及固定高度。周课表测试覆盖表头切周、取消与反向手势、正文分页、极窄屏，以及翻页过程中标题和视口位置不变。

完整周填写测试覆盖周一／周日模式、闰年和跨年、原生输入模式、非法星期禁选及取消不落盘。小组件在真实 AppWidgetHostView 上验证响应尺寸、集合点击和主题恢复；实际绘图保存在 [`widgets/`](../artifacts/qa-v1.7/widgets/)。

原有 13 项导出设备测试再次通过，完整学期 PNG／PDF、三语言、内容完整性和边框规则均保留，产物位于 [`export-validation/`](../artifacts/qa-v1.7/export-validation/)。下载增加 25 项 JVM 及 3 项设备用例，使用用户提供的乱码字符串与真实 XLS、GBK HTML，核对文件名、解析预览名称和 FileProvider 显示名。

显示验证使用独立 API 36 模拟器，编译及目标 SDK 为 API 37。测试包括真实 Material 控件的 F16 绘制和 HDR 动画色域转换；模拟器不具备物理 HDR／P3 显示能力，因此实机亮度、色域及观感仍待支持设备验证。软件渲染模拟器的帧时间仅作为环境诊断，不据此宣称实机帧率或性能改善幅度。
