## 本轮可靠性审查记录

1. 导出曾把未分配 `color=0` 改为具体默认色，破坏配置往返等价。已改为 Codec 原样保存颜色，导入引擎负责分配；原回归已通过。
2. 载入既有 8 天/2 周学期时，编辑器若把周数与终止日当作最近两项会扩展日期。已改默认优先保留已有起止日期，并覆盖默认构造与显式编辑顺序两条测试路径。
3. 纯 JSON 深嵌套输入、敏感附加字段和错误回显已加固。
4. 界面全量旧状态保存可能覆盖并发操作、导入确认后可变参数可能改写目标、今日后续课程不随时间更新：已复核差量状态提交、确认瞬间参数快照和 30 秒时钟刷新修复；设备操作待验。
5. 节假日已从固定公告相同文本校验改为真实日期解析，合法修订、补班变更与畸形拒绝单测通过；教学补课映射不得由国定补班日猜测。学校官方说明与数据范围见来源文档。
6. 重复点击同一桌面快捷入口曾可能不产生新路由事件；主实现已增加逐 Intent 的导航标识与设备回归测试。运行结果待报告。
