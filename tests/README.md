## 等价性验证

匿名化前先运行原有测试，固定原件及独立预期。匿名化后的预期由原有预期应用同一映射得到，没有调用应用解析器重新生成答案。

本地验证包括：

1. 备份逐字节校验；两份 HTML 经逆映射可恢复原文件的全部字节。
2. BIFF 记录及字符位置检查，以及 JExcelAPI 独立重读全部单元格、格式和工作表结构。
3. 六份原件与公开版本的完整解析结果对照，包括有序课程、授课记录、额外信息、待排时间、警告、错误及学期；忽略随机生成的课程 ID。
4. 可见字段、隐藏字段、OLE 元数据和仓库文本检查；以 UTF-8、UTF-16LE、GB18030 扫描已识别的真实身份值。
5. 原有逐字段解析回归及 `FixturePrivacyTest`。后者检查可见/隐藏学号、姓名和 BIFF 作者，补足业务解析器主动忽略的字段。

这些验证以本地真实导出为基准。此次教务网站直连未成功，尚未在线核实服务器导出流程。

公开检查不依赖私有文件：

```powershell
./tools/build.ps1 -Task ':core:test', ':app:testDebugUnitTest'
```

## 私有原件与发布

原件、原始预期、实体映射及一次性迁移核验脚本保存在 `tests/private/`，整个目录由根 `.gitignore` 排除。不要将原件临时放入公开样例目录，也不要使用 `git add -f` 添加私有目录。

新增样例时应先检查作者、隐藏输入、隐藏列、未引用字符串及填充区，再独立记录预期。保留声明编码与实际容器格式；扩展名 `.xls` 不能代替格式检查。

原件此前已进入本地 Git 历史。当前目录匿名化及 `.gitignore` **不会清除历史对象**。首次公开发布应从匿名化后的当前文件创建干净仓库，或另行完成并核验历史清理，避免直接推送旧历史。
